shared pattern

Every agent runs the same loop

The agents are deterministic first. Rules and statistics make every decision, so the result is the same on every run and each outcome traces back to a rule. Claude only writes the human-facing text (an email, a memo, a status note). Without an API key the agent still runs and falls back to a template.

  1. 01

    Ingest

    sample_data() returns DataFrames: invoices, balances, bank lines. Synthetic by default, so it runs with zero setup.

  2. 02

    Decide

    Rules, thresholds and simple stats score, match and classify each record.

  3. 03

    Route

    Clean items go straight through; exceptions get a status and a next action.

  4. 04

    Narrate

    Optionally, Claude turns the structured result into prose for the owner.

  5. 05

    Hand back

    AgentResult: KPI summary, action table, narrative, extras such as journals or payment files.
